# s08 Hook System

## 这章解决什么问题

在不改主循环结构的前提下，给系统加扩展点。

## 新增的核心状态

- `HookManager`
- hook 注册表
- 固定时机：`SessionStart / PreToolUse / PostToolUse`

## 新增的工具/接口

- 对模型来说几乎没有新工具
- 对系统来说，多了一层“在固定时机插入行为”的接口

## 接到主循环哪里

- session 开始时触发一次
- tool 执行前触发一次
- tool 执行后触发一次

## 和前面章节的边界

- hook 不是权限判断
- hook 不是零散的 `if` 分支

## 最小时序

1. 主循环进入某个固定时机
2. `HookManager` 找到对应 hook
3. hook 返回继续、阻断或注入消息
4. 主循环按约定继续

## 自己重写时最小要保留什么

- 一个 hook 注册器
- 明确的触发时机
- 统一的返回契约

## 一句话记忆

hook 的意义是“在主循环外加行为”，不是“把主循环改乱”。
