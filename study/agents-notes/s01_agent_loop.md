# s01 Agent Loop

## 这章解决什么问题

先建立最小可工作的 coding agent 主循环。

## 新增的核心状态

- `LoopState`：把 `messages` 和回合推进状态显式化

## 新增的工具/接口

- `bash`：最小可执行动作

## 接到主循环哪里

- `run_one_turn()` 负责一次模型调用和工具回流
- `agent_loop()` 负责反复推进直到本轮结束

## 和前面章节的边界

- 这章还没有复杂工具系统
- 这章最重要的不是命令执行，而是 `tool_result` 回流

## 最小时序

1. 用户输入写进 `messages`
2. 模型返回文本或 `tool_use`
3. 如果是 `tool_use`，执行 `bash`
4. 把 `tool_result` 追加回 `messages`
5. 继续下一轮

## 自己重写时最小要保留什么

- 一个显式状态对象
- 一次模型调用
- 一次工具执行
- 一次 `tool_result` 回流

## 一句话记忆

agent 的最小闭环不是“会调用模型”，而是“会把真实工具结果再喂回模型”。
