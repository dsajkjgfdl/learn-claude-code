# s06 Context Compact

## 这章解决什么问题

让 agent 在上下文变大时还能继续工作，而不是直接崩掉。

## 新增的核心状态

- `CompactState`
- 大输出落盘后的引用信息
- 历史压缩后的摘要状态

## 新增的工具/接口

- `compact`：手动触发压缩

## 接到主循环哪里

- 大工具输出先持久化到磁盘，只留 preview
- 较老的工具结果会被 micro-compact
- 整体上下文过大时触发会话级 summary

## 和前面章节的边界

- 压缩不是删除历史
- 压缩也不是长期记忆

## 最小时序

1. 工具输出太大
2. 完整内容落盘
3. 上下文里只保留简短标记
4. 对话继续变大时再做更高层摘要

## 自己重写时最小要保留什么

- 大输出持久化
- 预览标记
- 会话级压缩入口

## 一句话记忆

压缩的本质是把细节迁出活跃上下文，而不是假装这些细节不存在。
