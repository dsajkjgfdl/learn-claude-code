# s03 Todo Write

## 这章解决什么问题

把当前会话的计划从模型脑内拿出来，变成显式状态。

## 新增的核心状态

- `PlanItem`
- `PlanningState`
- `TodoManager`

## 新增的工具/接口

- `todo`：重写当前计划、更新步骤状态

## 接到主循环哪里

- 模型通过 `todo` 工具更新计划
- 主循环会按间隔注入 plan reminder，提醒模型刷新计划

## 和前面章节的边界

- 这是会话级计划，不是 durable task graph
- 它解决“这轮怎么做”，不是“长期要完成什么”

## 最小时序

1. 用户给出多步任务
2. 模型调用 `todo` 写出步骤
3. 系统保持一个 `in_progress` 步骤
4. 进展变化后再调用 `todo` 刷新

## 自己重写时最小要保留什么

- 一个计划状态对象
- 一个计划更新工具
- 一个定期提醒机制

## 一句话记忆

`todo` 管的是这次会话的工作节奏，不是长期任务板。
