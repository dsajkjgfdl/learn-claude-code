# 如何复习这套课

这套课最怕的不是“忘了细节”，而是“边界重新混掉了”。所以复习要以复述机制和区分边界为主，不要重抄源码。

## 第一轮复习：看总图

- 只看 `00_课程总图.md`
- 目标不是记函数名，而是记住 4 个阶段
- 你应该能闭卷回答：每个阶段到底在长什么

## 第二轮复习：看章节卡

- 每次只拿 3 到 5 章
- 每章只回答 4 个问题：
- 这章解决什么问题
- 新增了什么状态
- 接到主循环哪里
- 它和前一章的边界是什么

## 第三轮复习：闭卷默写主线

把整套课闭卷画成下面这条主线：

`messages -> model -> tool_use -> tool_result -> next turn`

然后在这条主线周围补上：

- `todo`
- `permission`
- `hook`
- `memory`
- `task`
- `background`
- `cron`
- `teammate`
- `worktree`
- `MCP`

## 最有效的自测方式

1. 为什么 `memory` 不是更长的上下文窗口？
2. 为什么 `background task` 不是 `task`？
3. 为什么 `teammate` 不是 `subagent` 放大版？
4. 为什么 `worktree` 不是 git 小技巧，而是执行隔离车道？
5. 为什么 MCP 必须接回同一条工具控制面？

## 最有效的巩固方式

- 从空目录自己重写一个最小 `agent_loop`
- 再逐步把 `todo / permission / memory / task / background` 加回去
- 每次只补一个机制，不要一口气抄 `s_full.py`

## 一句话记忆

复习这套课时，优先复习“边界和回路”，不要优先复习“函数和细节”。
